# Karsa Studio

**Karsa Studio** は、**オープンソース (非商用)** プロジェクトとしてリリースされた、フル機能でプロフェッショナルな *テキストから図へ (Text-to-Diagram)* 変換するエディターです。このアプリケーションは信じられないほど軽量で、非常に高速に動作し、すべてのデータをユーザーのブラウザー内（100％ クライアントサイド）で完全に処理します。このプロジェクトの主な目的は、開発者、システムアーキテクト、プロジェクトマネージャー、そして手動で描画することなく、コードを入力するだけでアイデア、アーキテクチャ、ワークフローを素早く視覚化する必要があるすべての人を支援することです。

このアプリケーションには以下から直接アクセスできます: **[karsa-studio.rivaldigunawanyusuf.com](https://karsa-studio.rivaldigunawanyusuf.com)**

## 主な機能

- **100% クライアントサイド & オフラインファースト：** すべての図のレンダリングはブラウザー内で直接実行されます。PWA（Progressive Web App）としてサポートされており、初回ロード後は完全にオフラインで使用できます。サーバーへの負荷はゼロで、外部サーバーに送信されるデータもゼロです。
- **専用の拡張システム：** 標準の `.mermaid`、`.md`、`.txt` ファイルをサポートします。さらに、単一ドキュメントを保存するための `.krs` や、複数ドキュメントのプロジェクトを保存するための `.karsa` といった独自のファイル拡張子も導入されています。
- **多言語 (i18n)：** ネイティブで 5 つの言語（英語、インドネシア語、中国語 (中文)、日本語、ロシア語 (Русский)）をサポートしており、リアルタイムで切り替えることができます。
- **ローカルドキュメント管理：** 複数の図のドキュメントを一度に作成できます。複数のドキュメントを簡単に選択して一括複製や一括削除が可能です。すべてのデータはブラウザーの `localStorage` に自動的に保存されます。
- **豊富なテンプレート：** 洗練された業界標準のテンプレート（アーキテクチャ、フローチャート、ER図、ガントチャート、マインドマップなど）が多数用意されています。
- **ダイナミックテーマとカスタマイズ：** ダーク/ライトモード、フォント設定、レイアウトエンジンの調整、カスタムスタイリング機能に対応しています。
- **高品質エクスポート：** クリック 1 つで、図を SVG（ベクター）、高解像度 PNG（最大 4x HD）、PDF などの様々なフォーマットにエクスポートしたり、コードを即座にコピーしたりできます。
- **レスポンシブ & クロスデバイス：** インターフェースは柔軟に設計されており、様々な画面サイズに対応しています。デスクトップでもモバイルデバイスでもスムーズに動作します。

## ローカルへのインストールと実行 (Mac / Linux / Windows)

このアプリケーションはバックエンドを必要としないため、標準のローカル開発サーバーを使用して実行するか、任意の静的ホスティングサービスにデプロイすることができます。

### 必要条件
- [Node.js](https://nodejs.org/) (バージョン 16 以上)

### 1. クイックスタート (自動スクリプト)
ルートディレクトリにヘルパースクリプトを用意しています。このスクリプトは、Node.js を自動的に確認し、依存関係をインストールし、利用可能なポートを見つけて、ローカルサーバーを起動します。

**Mac OS / Linux のユーザー：**
```bash
# スクリプトに実行権限を付与 (最初の1回のみ)
chmod +x start.sh

# スクリプトを実行
./start.sh
```

**Windows のユーザー：**
エクスプローラーで `start.bat` ファイルをダブルクリックするか、コマンドプロンプト / PowerShell から実行するだけです:
```cmd
start.bat
```

### 2. 手動での起動 (ステップバイステップ)
手動で実行したい場合や自動スクリプトが失敗する場合は、ターミナルで以下の手順に従ってください (Mac、Linux、Windows に対応):

```bash
# 1. プロジェクトフォルダーに入る
cd mermaid-studio

# 2. 依存関係をインストールする (最初のみ必要)
npm install

# 3. 開発サーバーを実行する
npm run dev

# 4. ブラウザを開き、ターミナルに表示された URL にアクセスする (通常は http://localhost:5173)
```

## キーボードショートカット

Karsa Studio は、ワークフローを高速化するための標準的なキーボードショートカットをサポートしています。修飾キーはオペレーティングシステムに基づいて自動的に適応します：
- **Mac OS:** `Cmd (⌘)` キーを使用します。
- **Windows / Linux:** `Ctrl` キーを使用します。

| アクション | ショートカット (Mac) | ショートカット (Windows/Linux) |
| :--- | :--- | :--- |
| **図の保存 / レンダリング** | `Cmd + S` | `Ctrl + S` |
| **コード編集の取り消し (Undo)** | `Cmd + Z` | `Ctrl + Z` |
| **コード編集のやり直し (Redo)** | `Cmd + Shift + Z` | `Ctrl + Y` または `Ctrl + Shift + Z` |
| **エディター内で検索** | `Cmd + F` | `Ctrl + F` |
| **エディター内で置換** | `Cmd + Option + F` | `Ctrl + H` |

アプリケーションは `http://localhost:5173/` で実行されます。

## 本番環境へのデプロイ (非常に簡単)

Karsa は **静的サイトアプリケーション (SPA)** として特別に設計されています。高価なデータベースサーバーや VPS をレンタルすることなく、無料でホスティングできます。

1. ビルドプロセスを実行します：
   ```bash
   npm run build
   ```
2. これにより、静的ファイル (HTML、CSS、圧縮された JS) が含まれる `dist/` フォルダが生成されます。
3. この `dist/` フォルダを、お好みの静的ホスティングサービス (Vercel、Netlify、GitHub Pages など) に直接アップロードできます。
4. ドメイン (karsa-studio.rivaldigunawanyusuf.com) をホスティングサービスに向けることを忘れないでください。

ユーザーがサイトを訪問すると、ユーザーのブラウザーがワークロード (図のレンダリング) を負担するため、サーバーに過負荷をかけることなく、大規模なトラフィックの急増に対して高い回復力を確保できます！

## テックスタック (技術構成)

- **フロントエンド ビルドツール:** Vite - 開発用に驚くほど高速。
- **図のエンジン:** JS ベースの Text-to-Diagram エンジン (クライアントサイド・レンダリング)。
- **コードエディター:** CodeMirror 6 - 快適なコード入力体験 (シンタックスハイライト付き)。
- **状態管理:** `localStorage` と統合された `EventTarget` アーキテクチャを使用したカスタムビルド (非常に軽量)。
- **画像エクスポート:** HTML5 Canvas API と PDF レンダリングモジュールを使用。
- **UI デザイン:** バニラ CSS (カスタムプロパティ/変数) とグラスモーフィズム (Glassmorphism) UI により、重い CSS フレームワークを使わずにメンテナンスを容易にします。

## このプロジェクトについて

Karsa Studio は、Mermaid.js のエコシステム上に構築された図表エディター (フロントエンドインターフェース) です。このアプリケーションは Mermaid のレンダリングエンジンとスクリプト構文を活用し、図表を動的に視覚化します。

このプロジェクトは元々、カスタマイズされたインターフェースを使用して図表作成を簡素化するという、個人的および社内のニーズのために作成されました。

現在、プロジェクトはオープンソース化されており、誰でも自由に使用できます。`karsa-studio.rivaldigunawanyusuf.com` でこのアプリケーションに無料でアクセスして使用できます。
