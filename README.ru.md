# Karsa Studio

**Karsa Studio** - это полнофункциональный, профессиональный редактор для преобразования *текста в диаграммы (Text-to-Diagram)*, выпущенный как проект с **открытым исходным кодом (некоммерческий)**. Это невероятно легкое и быстрое приложение, которое обрабатывает все данные полностью в браузере пользователя (100% на стороне клиента). Главная цель этого проекта - помочь разработчикам, системным архитекторам, менеджерам проектов и всем, кому необходимо быстро визуализировать идеи, архитектуру и рабочие процессы с помощью простого написания кода, избавляя от необходимости рисовать вручную.

Приложение доступно по ссылке: **[karsa.rivaldigunawanyusuf.com](https://karsa.rivaldigunawanyusuf.com)**

## Основные возможности

- **100% Client-Side и Offline-First:** Весь рендеринг диаграмм выполняется непосредственно в вашем браузере. Поддерживается как PWA (Progressive Web App), и может использоваться полностью автономно после первой загрузки. Нулевая нагрузка на сервер, и никакие данные не отправляются на внешние серверы.
- **Эксклюзивная система расширений:** Поддерживает стандартные файлы `.mermaid`, `.md` и `.txt`. Также вводит проприетарные расширения: `.krs` для сохранения одиночных документов и `.karsa` для сохранения проектов с множеством документов.
- **Мультиязычность (i18n):** Нативная поддержка 5 языков (английский, индонезийский, китайский, японский и русский), которые можно переключать в реальном времени.
- **Локальное управление документами:** Вы можете создавать несколько документов с диаграммами одновременно. Легко выбирайте несколько документов для массового дублирования или удаления. Все данные автоматически сохраняются в `localStorage` вашего браузера.
- **Богатый набор шаблонов:** Десятки улучшенных стандартных шаблонов для индустрии (Архитектура, Блок-схемы, ER-диаграммы, Диаграммы Ганта, Ментальные карты и др.).
- **Динамические темы и кастомизация:** Поддержка темного/светлого режимов, настройки шрифтов, изменения движка компоновки и функции пользовательского стиля.
- **Высококачественный экспорт:** Экспорт диаграмм в один клик в различные форматы, такие как SVG (Вектор), PNG высокого разрешения (до 4x HD), PDF, или мгновенное копирование кода.
- **Адаптивность и кроссплатформенность:** Интерфейс гибко спроектирован для поддержки экранов различных размеров. Плавно работает как на ПК, так и на мобильных устройствах.

## Локальная установка и запуск (Mac / Linux / Windows)

Поскольку это приложение не требует бэкенда, вы можете запустить его с помощью стандартного сервера разработки или развернуть на любом сервисе статического хостинга.

### Требования
- [Node.js](https://nodejs.org/) (версия 16 или выше)

### 1. Быстрый старт (Автоматический скрипт)
Мы подготовили вспомогательные скрипты в корневом каталоге, которые автоматически проверяют наличие Node.js, устанавливают зависимости, находят свободные порты и запускают локальный сервер.

**Для пользователей Mac OS / Linux:**
```bash
# Сделайте скрипт исполняемым (требуется только один раз)
chmod +x start.sh

# Запустите скрипт
./start.sh
```

**Для пользователей Windows:**
Просто дважды щелкните файл `start.bat` в Проводнике или запустите его через Командную строку (CMD) / PowerShell:
```cmd
start.bat
```

### 2. Запуск вручную (Шаг за шагом)
Если вы предпочитаете запускать вручную или если автоматические скрипты не работают, выполните следующие шаги в терминале (совместимо с Mac, Linux и Windows):

```bash
# 1. Перейдите в папку проекта
cd mermaid-studio

# 2. Установите зависимости (требуется только первый раз)
npm install

# 3. Запустите сервер разработки
npm run dev

# 4. Откройте браузер и перейдите по URL, указанному в терминале (обычно http://localhost:5173)
```

## Горячие клавиши (Keyboard Shortcuts)

Karsa Studio поддерживает стандартные сочетания клавиш для ускорения вашего рабочего процесса. Клавиша-модификатор автоматически адаптируется в зависимости от вашей операционной системы:
- **Mac OS:** Используйте клавишу `Cmd (⌘)`.
- **Windows / Linux:** Используйте клавишу `Ctrl`.

| Действие | Сочетание (Mac) | Сочетание (Windows/Linux) |
| :--- | :--- | :--- |
| **Сохранить / Отрендерить диаграмму** | `Cmd + S` | `Ctrl + S` |
| **Отменить редактирование (Undo)** | `Cmd + Z` | `Ctrl + Z` |
| **Повторить редактирование (Redo)** | `Cmd + Shift + Z` | `Ctrl + Y` или `Ctrl + Shift + Z` |
| **Найти в редакторе** | `Cmd + F` | `Ctrl + F` |
| **Заменить в редакторе** | `Cmd + Option + F` | `Ctrl + H` |

Приложение будет запущено по адресу `http://localhost:5173/`.

## Развертывание в продакшене (Очень просто)

Karsa специально спроектирована как **Static Site Application (SPA)**. Вы можете разместить ее бесплатно, без необходимости арендовать дорогостоящие базы данных или VPS.

1. Запустите процесс сборки:
   ```bash
   npm run build
   ```
2. Будет сгенерирована папка `dist/`, содержащая статические файлы (HTML, CSS и сжатый JS).
3. Вы можете напрямую загрузить эту папку `dist/` на любой предпочтительный сервис статического хостинга (например, Vercel, Netlify, GitHub Pages).
4. Не забудьте направить ваш домен (karsa.rivaldigunawanyusuf.com) на этот сервис.

Когда пользователи будут посещать ваш сайт, их браузер возьмет на себя вычислительную нагрузку (рендеринг диаграмм), гарантируя, что ваш сайт будет устойчив к массивным всплескам трафика без перегрузки сервера!

## Технологический стек

- **Инструмент сборки Frontend:** Vite - невероятно быстр для разработки.
- **Движок диаграмм:** JS-движок Text-to-Diagram (рендеринг на стороне клиента).
- **Редактор кода:** CodeMirror 6 - для комфортного ввода кода (с подсветкой синтаксиса).
- **Управление состоянием:** Собственная сборка с использованием архитектуры `EventTarget` (очень легкая) с интеграцией `localStorage`.
- **Экспорт изображений:** Использует HTML5 Canvas API и модуль рендеринга PDF.
- **Дизайн UI:** Чистый CSS (кастомные свойства/переменные) и интерфейс Glassmorphism для легкого обслуживания без тяжелых CSS фреймворков.
