**Karsa Studio** — это полнофункциональный профессиональный редактор диаграмм из текстового описания (*Text-to-Diagram*), выпущенный под лицензией **Open Source (некоммерческое использование)**. Приложение работает на 100% внутри вашего веб-браузера: рендеринг и обработка данных выполняются локально, ни один байт ваших диаграмм не передаётся на сторонние серверы. Сочетая мощь декларативного кода с удобством интерактивного холста в стиле Figma, Karsa Studio помогает разработчикам, системным архитекторам, продакт-менеджерам и техническим писателям за считанные секунды превращать идеи и архитектуры в презентабельные диаграммы.

🌐 **Онлайн-версия:** [karsa-studio.rivaldigunawanyusuf.com](https://karsa-studio.rivaldigunawanyusuf.com)

## 🚀 Основные преимущества и возможности

### 🔒 100% клиентская работа, полная приватность и Offline-First (PWA)
- **Нулевая задержка:** Синтаксический анализ и отрисовка выполняются мгновенно через Web Workers и локальный JavaScript.
- **Бескомпромиссная конфиденциальность:** Ваши закрытые схемы инфраструктуры, базы данных и алгоритмы никогда не покидают компьютер.
- **Progressive Web App (PWA):** Возможность установки как отдельного приложения на рабочий стол или смартфон. Полная автономная работа без подключения к интернету.

### 🎨 Интерактивный холст в стиле Figma
- **Панорамирование через Space + Drag:** Зажмите клавишу `Пробел (Space)` и перетаскивайте холст курсором для плавного скольжения по бесконечному пространству, как в Figma или Miro.
- **Интуитивное масштабирование:** Масштабирование через `Ctrl/Cmd + Колёсико мыши`, жесты сведения пальцев на тачпаде или экранные кнопки.
- **Быстрое центрирование:** Мгновенный масштаб 1:1 (`Cmd/Ctrl + 1`) и подгонка под размер экрана (`Cmd/Ctrl + 0` или двойной клик по холсту).
- **Стили фона холста:** Точки (Dots), сетка (Grid), однотонный фон (Plain) и прозрачность (Transparent).

### 💻 Продвинутый редактор CodeMirror 6
- **Подсветка синтаксиса и валидация:** Обнаружение ошибок на лету с индикатором строк и всплывающими подсказками.
- **Плавная прокрутка на ПК и смартфонах:** Точные границы контейнера со скроллом колёсиком, тачпадом и плавным инерционным касанием на мобильных устройствах.
- **Панель быстрой вставки:** Вставка узлов, ромбов решений, подграфов (Subgraph), баз данных, кругов, пунктирных линий и стрелок в 1 клик.
- **Инструменты Pro-редактирования:** Мультикурсор (`Alt + Клик`), сворачивание блоков кода, автозакрытие скобок, комментирование (`Cmd/Ctrl + /`), поиск и замена (`Cmd/Ctrl + F`).
- **Гибкий макет:** Регулируемый разделитель экрана, переключение горизонтальной/вертикальной ориентации, фокус на редакторе или полноэкранный предпросмотр.

### 📚 24 встроенных отраслевых шаблона диаграмм
Готовые профессиональные примеры, сгруппированные по 6 направлениям:
1. **Блок-схемы и процессы:** Стандартный Flowchart, архитектурная схема (LR), конечный автомат (State Machine).
2. **Базы данных и код:** Реляционная ER-диаграмма (PK/FK), диаграмма классов ООП, матрица требований, структура байтов сетевого пакета.
3. **Взаимодействия и системы:** Диаграмма последовательности (Sequence Auth), облачная архитектура, контекстная диаграмма C4, блочная архитектура.
4. **Планирование и таймлайн:** Диаграмма Ганта, хронология развития продукта, карта пути пользователя (User Journey), канбан-доска, граф веток Git.
5. **Аналитика и данные:** Круговая диаграмма (Pie Chart), график метрик XY, матрица приоритетов 2x2, поток ресурсов Сэнки (Sankey), лепестковая диаграмма (Radar), Treemap.
6. **Генерация идей:** Интеллект-карта (Mindmap) и чистый стартовый холст.

### 🎭 Темы оформления и гибкая кастомизация
- **Темная и светлая темы:** Мягкий переход между глубоким стеклянным неоморфизмом (Glassmorphism) и контрастным светлым режимом.
- **Темы Mermaid:** Default, Neutral, Forest, Dark и Base.
- **Стилистические пресеты:** Ручной набросок (Sketch), минимализм, современный, неоморфизм, киберпанк, ретро, пастель, высокий контраст.
- **Движки авто-размещения:** Классический Dagre и ELK (Eclipse Layout Kernel) для сложных разветвленных графов.
- **Настраиваемая палитра:** Индивидуальный выбор цветов для узлов, линий, текста, рамок, подграфов и заметок.

### 📤 Экспорт во множество форматов и обмен без сервера
- **Векторный и растровый экспорт:** Векторный SVG, сверхчёткий PNG (до 4x HD разрешения) и PDF.
- **Копирование в буфер обмена в 1 клик:** Исходный код Mermaid, блок разметки Markdown (готов для Notion, GitHub, Obsidian), код SVG или PNG-изображение.
- **Шеринг ссылок без базы данных:** Передача диаграмм через хеш-ссылки со сжатием `pako` zlib deflate. Получатель открывает диаграмму и тему без регистрации и запросов к бэкенду.
- **Резервное копирование:** Сохранение отдельных файлов `.krs` / `.mmd` или резервная копия всех документов в формате `.karsa` / `.json`.

### 🌐 Поддержка 5 языков (i18n)

## 🛠️ Локальный запуск и разработка

Приложение не требует сервера или базы данных, поэтому локальный запуск занимает меньше минуты:

### Системные требования
- [Node.js](https://nodejs.org/) (версия 18 или новее)
- Пакетный менеджер `npm`, `pnpm` или `yarn`

### 1. Автоматический запуск скриптом

**macOS / Linux:**
```bash
# Дать права на выполнение (только в первый раз)
chmod +x start.sh

# Запуск стартового скрипта
./start.sh
```

**Windows:**
Дважды кликните по файлу `start.bat` в проводнике или выполните в консоли:
```cmd
start.bat
```

### 2. Ручная установка
```bash
# Клонировать репозиторий
git clone https://github.com/rivaldigunawanyusuf/karsa-studio.git
cd karsa-studio

# Установить зависимости
npm install

# Запустить сервер разработки Vite
npm run dev
```

Откройте в браузере адрес `http://localhost:5173/`.

## 🚀 Развёртывание в Production

Karsa Studio собирается как чистое, оптимизированное **статическое веб-приложение (SPA)**:

```bash
# Сборка продакшен-бандла
npm run build
```

Все файлы компилируются в каталог `dist/`. Вы можете опубликовать содержимое `dist/` на любом статическом хостинге:
- **Cloudflare Pages**
- **Vercel**
- **Netlify**
- **GitHub Pages**
- **Собственный Nginx / Apache / Caddy** (используйте `nginx-security.conf` для настройки защитных заголовков CSP, HSTS и др.)
